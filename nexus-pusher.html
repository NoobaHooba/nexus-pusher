NexusPusher
Upload artifacts to your Nexus repo

Upload to Nexus

Select a repository type, fill in the details, then drag & drop or select your files.

☕ Maven Repository Upload

Uploads a Maven artifact to a hosted Maven repository via the Nexus REST API. The asset path will be /{groupId}/{artifactId}/{version}/{artifactId}-{version}.jar

Leave empty for the main artifact.
📦 npm Repository Upload

Upload .tgz npm package tarballs. Create them locally with npm pack then upload here.

🔷 NuGet Repository Upload

Upload .nupkg NuGet packages to a hosted NuGet repository using the NuGet v2/v3 push endpoint.

🐍 PyPI Repository Upload

Upload Python distribution files (.whl, .tar.gz) to a hosted PyPI repository.

🐳 Docker Repository Upload

Upload Docker image .tar archives (exported via docker save) to a hosted Docker registry. The app will parse the manifest and push each layer.

Docker uses its own port (usually 8082). The file must be a .tar exported with docker save.
📀 Yum (RPM) Repository Upload

Upload .rpm packages to a hosted Yum repository. Files are placed under the specified directory path.

Path within the repo (e.g. /7/x86_64/)
🦌 Apt (Debian) Repository Upload

Upload .deb packages to a hosted Apt repository. Specify the distribution and component for correct indexing.

⛵ Helm Repository Upload

Upload Helm chart archives (.tgz) to a hosted Helm repository. Package charts with helm package . before uploading.

📁 Raw Repository Upload

Upload any file to a raw repository. Specify the destination directory path within the repository.

All files will be uploaded under this path. Each file keeps its own filename.
